# 唱一句 · 定调子 🎸

一个**吉他新手定调器**：对着手机唱一句副歌，它立刻告诉你——

- **是什么调**（D 大调 / Am 小调…）
- **do 在吉他上的位置**（几弦几品）
- **怎么弹**（用 C 调指法变调夹夹几品，或直接弹本调开放和弦）
- **这个调的常用和弦**

全程浏览器本地运行，**声音不上传**，无服务器，无账号，无成本。

## 怎么打开

| 方式 | 说明 |
|---|---|
| **双击 `index.html`** | 最快。用 Chrome / Edge / Safari 打开 |
| **跑 `启动.bat`** | 可启动本地服务器，手机连同一 Wi-Fi 访问 |

> 浏览器首次会请求麦克风权限，请点"允许"。若双击打不开麦克风（个别浏览器限制 `file://`），用 `启动.bat` 方式 2。

## 怎么用（30 秒上手）

1. **长按**麦克风按钮，开始唱歌
2. 唱**一句副歌**（4~8 秒，每个音稳住半秒以上），**松手**
3. 立刻出结果：
   - 大主卡片：调名 + 识别信心
   - 你唱的旋律转成首调唱名（do re mi…）——**顺便练首调听辨**
   - do 的位置 + 指板图
   - 变调夹建议 + 常用和弦 + 新手提示
4. 可以点"♪ 听一下旋律"回放你刚唱的音

**提示**：唱的越完整、越稳，识别越准。唱得偏低/偏高也没关系（内置了 ±40 音分补偿）。

## 技术

| 模块 | 实现 |
|---|---|
| 音高检测 | **YIN**（CMNDF，比朴素自相关抗跑音/八度误判），44.1kHz/2048 窗口 |
| 音符分段 | 中值滤波 + 跳变切分 + 短音合并 |
| 调性识别 | **Krumhansl-Schmuckler** 探测音评分 + 时长加权 + 落尾音权重 + 吉他友好微调 + 全局音分偏移搜索（兼容跑音） |
| 吉他映射 | 24 个大小调数据表（do 位置经 MIDI 逐项验算）+ 变调夹/开放和弦双方案 |
| 界面 | 单文件 HTML，移动端优先，深色主题 |

核心 DSP 逻辑（`dsp.js` / `key.js` / `guitar-map.js`）为纯函数、零依赖，可独立复用/测试。`index.html` 为自包含版本（同一份逻辑内联）。
