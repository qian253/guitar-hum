# humkey-ui:唱一句·定调子 设计规范与用户好恶

## 产品与风格定位
- 产品:对着手机哼一句,告诉你什么调+夹几品+怎么弹。用户=怕乐理、想轻松弹唱的吉他新手。
- 风格:**手绘治愈系**(燕麦纸底+手绘线描+音乐猫伙伴+轻游戏化),不是极简、不是商务、不是暗色系。
- 一句风格锚点:"像在一本手绘乐谱笔记本上,和一只戴耳机的小猫一起玩音乐。"

## 设计令牌(唯一配色来源,禁止系统外颜色)

装饰元素(水彩块/漂浮物)透明度 ≤0.22

## 用户好恶清单(血泪教训,违反=返工)
**喜欢**:
- 手绘不规则圆角卡片;手写体标题(ZCOOL KuaiLe);猫爪🐾emoji(单爪,召唤按钮);蒲公英+种子飘散粒子;猫爪夹品动画"夹这里!";逐字书写调性名+下划线;情绪描述句;软陶按压感;胶囊标签;收集徽章;陪伴问候
**讨厌(踩过的坑,别再犯)**:
- 满屏 wobbly 描边线(已整层删除);装饰 emoji 当图标(已换 Lucide 线性 SVG);按住时红色圆环脉冲(只留种子残影);按钮深色描边框;大段专业名词默认可见(藏到"为什么"/专家模式);一屏多主角;页面顶部大片空白;长页滚不到底(用横向分页);错误提示常驻(5 秒淡出)

## 布局铁律
- 一屏一个主行动;主按钮≥120px 居中;点击区≥48px;关键信息(调性名/变调夹)首屏可见;每页手绘圈注最多一个
- 页面结构:测调页(顶栏→蒲公英录音→今日一调→实时音名→场景插画→底栏)/ 结果页(调名大字→猫爪夹品图→信心条→情绪句→标签页:简谱|怎么弹(横向2页:左手和弦/右手节奏)→吸底:分享+再测)/ 练习页(闯关+猜调挑战)/ 我的页(一张卡:陪伴+动物墙+收集册(点徽章筛记录)+折叠历史+设置)

## 动效
- 全部≤1.2s,只用 transform/opacity;调性名逐字 100ms/字;蒲公英粒子 240ms/颗;尊重 prefers-reduced-motion;页面切换 0.34s 淡入上移

## 组件规范
- 按钮:主按钮珊瑚渐变;次级白底 line 描边;胶囊 mini 按钮(38px,999px 圆角);不规则圆角 18/14/20/14
- 图标:内置 ICONS 21 个 Lucide 线性 SVG(data-ic 占位,fillIcons 填充),新增图标沿用 2px 圆头描边
- 猫:catSvg 7 表情+眨眼(cat-blink)+换装(catAccessory:3天🎀/7天🧣/14天👑)
- 分享卡片:640×800 canvas 手绘 PNG

## AI 味避雷(来自官方 frontend-design 技能)
避免三种默认脸:①奶油底+衬线大标题+陶土点缀(注意:我们选了奶油底,所以必须用手绘线描+猫角色+蒲公英签名元素拉开差异)②纯黑底+荧光绿 ③报纸栏式零圆角。设计前先问:这个选择是"这个产品必须的"还是"任何产品都会这么做的"?

## 工作流
改 UI 前:读本技能 → 想清楚签名元素 → 改 index.html(单文件,主脚本=核心逻辑/第二脚本=UI层/第三脚本=体验层,跨层用 window.__hkCat/__hkCore 桥接)→ 语法检查(6 个 script 块 node --check)→ 控制台零报错(headless Edge)→ 10 套回归 → 提交。
